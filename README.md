# Monorepo Docs Test

This repository is a tiny monorepo-shaped Mintlify docs fixture for testing
deployments with a non-root content directory.

Use this deployment git source:

```json
{
  "type": "github",
  "owner": "rtbarnes",
  "repo": "monorepo-docs-test",
  "deployBranch": "main",
  "contentDirectory": "apps/docs",
  "isPrivate": false
}
```
