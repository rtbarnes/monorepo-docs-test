# Quickstart

This page is intentionally simple so a workflow can make a low-risk edit during
the Vercel harness test.

## Test Checklist

- Confirm the deployment has `contentDirectory` set to `apps/docs`.
- Enable `force-workflows-vercel-harness` for the dev subdomain.
- Run a fresh workflow instance.
