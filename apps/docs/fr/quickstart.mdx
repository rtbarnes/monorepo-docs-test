# Démarrage rapide

Cette page est volontairement simple afin qu'un workflow puisse effectuer une
modification à faible risque pendant le test du harnais Vercel.

## Liste de vérification du test

- Vérifiez que le déploiement a `contentDirectory` défini sur `apps/docs`.
- Activez `force-workflows-vercel-harness` pour le sous-domaine de développement.
- Exécutez une nouvelle instance de workflow.

## Contenu du test de fumée

Cette note a été ajoutée pour vérifier qu'un nouveau contenu de documentation
peut être publié depuis le fixture de docs du monorepo.
